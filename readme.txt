スマブラSPの大会で使用するサムネイルを制作するジェネレーターです。

基本情報
インターネットに接続されている環境で使用してください。
1P、2P、大会情報に任意の文字列を入力すると、プレビューにすぐ反映されます（ファイターは入力が止まってから約0.6秒後に読み込みます）。
スライダーでファイター毎の倍率やX、Y位置を設定してください。文字情報と違い、リアルタイムで更新されます。
 (正常に動作していればスライダーの情報はファイター毎に保存されます。二回目以降そのファイターを指定する場合は前回の倍率・位置を参照します。）
 スライダーの情報は枠の中心を基準にしています。同ファイターの場合1P、2Pで設定しなおす必要はありません。
 ファイター画像を配置している階層は同じです。顔が小さく、横に大きいキャラクターの倍率を高く設定すると、1P(2P)側にキャラクターの一部がはみ出す可能性があります。注意してください。
入力内容はブラウザに保存され、ページを更新しても残ります。初期状態に戻したい場合は「入力内容を初期状態に戻す」を押してください。

各ボタンの説明
1P ⇄ 2P
1Pと2Pの入力内容（ファイター・アイコン・名前・チーム名）を入れ替えます。

位置・倍率をリセット
表示中のファイターのスライダー設定を初期値に戻します。

PNG書き出し
現在ジェネレーターのキャンバス上に表示されている画面を1920*1080で書き出します。ダウンロードフォルダに自動的に保存されます。
ファイル名は『開催回_ラウンド_1P名_vs_2P名.png』になります。

本戦用・予選用
クリックすることで別背景の画像に差し替えます。予選総当たり制を採用する場合や、BO5ラインを視覚的に区別したい場合に使用してください。



ファイターの名前を間違えて入力すると、入力欄が赤くなり、画面上部にエラーが表示されます。
以下入力規則
・日本語非対応。ファイターネームは英語入力
・大文字小文字は区別しない
・名前に『＆』や『and』を利用する、または2つ以上の英単語を使用するファイターは『_』を使用すること(例:young_link、banjo_and_kazooie)。
・名前に『.』を含む場合、省略する(例:mr_game_and_watch、rob)。
※ver1.4.0から表記ゆれを自動で補正します。スペースや『&』『.』入り(例: Mr. Game & Watch)、min_min / minmin、dark_pit / black_pit、ice_climbers / ice_climber、homura / hikari などはどちらでも動作します。

また、現時点では下Bが交代に当てられているファイターの個別のアセットを探せていません(mythraやsquirtle、mii_brawlerなど)。個別に作成しますのでご連絡ください。

入力内容をブラウザに保存し、ページを更新しても残るようにしました。
1P ⇄ 2P 入れ替えボタン、スライダーの数値表示とリセットボタン、今日の日付ボタン、ラウンド名の予測変換を追加しました。

pyraの立ち絵が表示されない不具合を修正しました。
キャンバスの文字をNoto Serif JP / Nunito Sansで描画するようにし、端末によって書き出し結果が変わらないようにしました。
画像が見つからない場合、入力欄とステータス表示でお知らせするようにしました。
